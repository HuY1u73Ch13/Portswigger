## Web Cache Deception

### Định nghĩa
Web Cache Deception là kỹ thuật lừa cache (CDN, proxy) lưu **nội dung cá nhân** thành public, khiến người khác truy cập được dữ liệu riêng tư.

### Những chỗ thường dính
- Trang profile
- Trang có session
- URL có đuôi `.css`, `.js`, `.jpg`
- CDN cấu hình cache sai

## OS Command Injection

### Định nghĩa
OS Command Injection cho phép attacker **thực thi lệnh hệ điều hành** trên server thông qua input không được kiểm soát, dẫn đến chiếm toàn quyền hệ thống.

### Những chỗ thường dính
- Chức năng ping, traceroute
- Import / export
- Backup hệ thống
- Chạy script từ web

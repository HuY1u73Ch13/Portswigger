## Authentication

### Định nghĩa
Authentication Vulnerability liên quan đến lỗi trong quá trình **xác thực danh tính người dùng**, cho phép attacker **bypass login, chiếm tài khoản hoặc giả mạo phiên đăng nhập**.

### Những chỗ thường dính
- Login, logout
- Forgot password / Reset password
- OTP, MFA
- JWT, session cookie
- API login không giới hạn số lần thử
